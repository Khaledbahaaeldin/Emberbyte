Expanding pill with spring physics

Tap a tab or drag across the bar. The pill's two edges are separate springs: the leading edge shoots ahead, the trailing edge follows, so it stretches and then settles. The bar itself never changes size.

How it maps to Compose. Each pill edge is an Animatable<Float> animated with spring(dampingRatio, stiffness); the leading edge uses a higher stiffness than the trailing one. Dragging sets the edges directly (no animation) and on release the finger velocity is handed to the springs (animateTo(target, initialVelocity)), so a flick carries on with its own momentum. Retargeting mid-flight keeps position and velocity, so it never jumps. With "Remove animations" on, the pill just moves to its place.
