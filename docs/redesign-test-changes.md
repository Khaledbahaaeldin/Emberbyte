# Redesign Test Changes and Replaced Tests Mapping

In Task A13 (The Compact Navbar), the legacy glass pill navigation bar (`FloatingPillNavBar`) and glass blur backdrop (`GlassSource` via Haze) were removed and replaced by `CompactNavBar` (solid pill with equal 68dp slots, elastic pill follow, and fixed width) and `PlusButton`.

The obsolete tests covering glass blur were retired. All other behavioral test cases (selection, drag-snap, hide/show on scroll, accessibility semantics and roles, touch targets, and RTL) are covered by the new test suite `CompactNavBarTest`.
