# Redesign QA Polish Items Closure (D5 to D14)

Review of M6 QA polish items (from `docs/accessibility-audit.md` section "Known polish items", D5 to D14) addressed during the Expressive Redesign:

- **D5**: Home 7-day row requires 384dp but card provides 361dp (today's bar cut at rest) — Closed in Task B6 by setting `openAtEnd = true` on `UsageBarRow` in `HomeSections.kt`, verified by `HomeContentTest.home_7_day_row_opens_at_end_showing_todays_bar_at_rest`.
- **D6**: App detail opens 7-day row at end while Home opens at start — Closed in Task B6 by unifying `openAtEnd = true` across both Home and App detail, verified by `HomeContentTest.home_7_day_row_opens_at_end_showing_todays_bar_at_rest` and `AppDetailScreenTest.daily_chart_has_a_text_alternative_for_each_bar`.
- **D7**: History selected bar shows no value/period readout on screen for sighted users — Closed in Task B5 (commit `4b66525`) by `HistoryHeader` and selected-bar readout card in `History.kt` (`NetworkBar` with Mobile and Wi-Fi readouts), verified by `HistoryScreenTest.comparison_is_text_with_an_icon_and_never_only_colour`.
- **D8**: Create backup dialog at font scale 2.0 with keyboard open: buttons hidden behind IME — Out of scope for M8 (dialogs milestone M10); previously fixed in Fix Wave commit `8798cb3`, verified by `create_backup_dialog_at_font_scale_2_keeps_create_and_cancel_reachable_and_clickable`.
- **D9**: Apps filter chip "This month" cut at right edge at font 2.0 — Closed in Task B3 (commit `e0cd18f`) by `FiltersSheet` modal bottom-sheet and horizontal scroll container for active filter chips in `AppsScreen.kt`, verified by `AppsScreenTest.each_non_default_filter_shows_a_removable_chip_with_a_remove_action_described`.
- **D10**: Plan and budget editors show long decimal figures in MB for GB-sized values — Out of scope for M8; scheduled for Milestone 9 (Plan flow and plan/budget editor redesign).
- **D11**: Density 660 splits number and unit across lines on History summary tiles — Closed in Task B5 (commit `4b66525`) by `HeroNumber` auto-shrinking text logic and `BentoTile` responsive layout in `HistoryHeader.kt`, verified by `HistoryScreenTest.total_is_one_node` and `HistoryScreenTest.font_scale_2_no_clip`.
- **D11b**: Plan editor "Not tied to a SIM" radio row height was 44dp (< 48dp) — Out of scope for M8 (plans editor milestone M9); previously fixed in F2 commit `d75bc0c`, verified by `plan_editor_touch_targets_are_at_least_48dp`.
- **D12**: Progress ring empty track at 0% has faint contrast (1.06:1) — Closed in M7 Task A11 (commit `f614457`) by `WavyRing` with visible contrast-checked track, verified by `PaletteContrastTest.every_pair_passes_in_every_theme_and_mode`.
- **D13**: Pseudo-locale `ar-XB` does not exercise RTL in app without locale resource — Closed in M7 Task A16 proof repair (commit `60c2394`) by testing with real Arabic (`ar`) system locale, verified by `CompactNavBarTest.tabs_are_ordered_right_to_left_in_rtl` and real RTL emulator screenshots.
- **D14**: English text with punctuation in RTL context misplaces punctuation at line start — Closed in M7 Task A13 (commit `31ba4da`) and M8 core screens by `ForceLtr` wrappers on English text, units, and timestamps, verified by `HomeContentTest.rtl_layout_direction_isolates_home_subtitle_with_force_ltr` and `HistoryScreenTest.rtl`.
